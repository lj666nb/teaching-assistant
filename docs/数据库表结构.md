# 学科助教系统 Edu-TA — 数据库表结构总览

> 基于 `backend/app/models/database.py`，共 **11 张表**，按功能模块分组。
> 主键带 `*` 标记的为自增整数，其余均为文本 UUID。

---

## 一、智能备课

### 1. `lesson_plans` — 教案

| 字段 | 类型 | 说明 |
|------|------|------|
| id * | TEXT | 主键（UUID） |
| course_name | TEXT (索引) | 课程名称 |
| chapter | TEXT | 章节名称 |
| total_hours | INTEGER | 课时数，默认 2 |
| additional_requirements | TEXT | 附加要求（如"偏重实践"） |
| plan_data | TEXT (JSON) | 完整教案 JSON（目标/活动/作业/板书/评价量规） |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间（自动更新） |

---

## 二、作业批改

### 2. `homework_grades` — 作业批改结果

| 字段 | 类型 | 说明 |
|------|------|------|
| id * | TEXT | 主键（UUID / seed_xxxx / manual_xxxx） |
| student_name | TEXT | 学生姓名 |
| course_name | TEXT (索引) | 课程名称 |
| chapter | TEXT | 所属章节 / 班级名 |
| question_text | TEXT | 题目内容 |
| student_answer | TEXT | 学生答案 |
| question_type | TEXT | 题型（选择题/填空题/主观题/计算题/手动录入等） |
| max_score | FLOAT | 满分，默认 100 |
| score | FLOAT | 得分 |
| percentage | FLOAT | 得分百分比 (0-100) |
| feedback | TEXT | 综合评语 |
| strengths | TEXT (JSON) | 优点列表 |
| weaknesses | TEXT (JSON) | 不足与错误 |
| suggestions | TEXT (JSON) | 改进建议 |
| knowledge_points | TEXT (JSON) | 涉及知识点 |
| detailed_analysis | TEXT | 逐句/逐步详细分析 |
| source_file | TEXT | 来源文件名 |
| batch_id | TEXT | 同一批次上传的标识 |
| is_archived | BOOLEAN | 是否已归档至教学台账 |
| **project_id** | TEXT (索引) | 数据来源项目（ta-project / student-project） |
| created_at | DATETIME | 创建时间 |

### 3. `exercise_batches` — AI 出题批次

| 字段 | 类型 | 说明 |
|------|------|------|
| id * | TEXT | 主键（UUID） |
| course_name | TEXT (索引) | 课程名称 |
| chapter | TEXT | 章节 |
| difficulty | TEXT | 难度（简单/中等/困难） |
| total | INTEGER | 题目总数 |
| exercises_json | TEXT (JSON) | 完整题目列表 |
| created_at | DATETIME | 创建时间 |

## 三、教学资料与题库

### 4. `materials` — 教学资料

| 字段 | 类型 | 说明 |
|------|------|------|
| id * | TEXT | 主键（UUID / seed_xxxx） |
| filename | TEXT | 文件名 |
| course | TEXT (索引) | 所属课程，默认"未分类" |
| chapter | TEXT | 所属章节 |
| size_bytes | INTEGER | 文件大小（字节） |
| size_display | TEXT | 文件大小（可读，如"2.3 MB"） |
| pages | INTEGER | 页数 |
| text_preview | TEXT | 文本预览（前若干字） |
| text_content | TEXT | 全文内容 |
| file_path | TEXT | 文件存储路径 |
| **project_id** | TEXT (索引) | 数据来源项目 |
| created_at | DATETIME | 创建时间 |

### 5. `questions` — AI 生成题目

| 字段 | 类型 | 说明 |
|------|------|------|
| id * | TEXT | 主键（UUID） |
| batch_id | TEXT (索引) | 所属批次 ID |
| course | TEXT | 课程名称 |
| question | TEXT | 题目内容 |
| type | TEXT | 题型（选择题/填空题/简答题） |
| options | TEXT (JSON) | 选择题选项 |
| answer | TEXT | 参考答案 |
| difficulty | TEXT | 难度 |
| knowledge_point | TEXT | 知识点 |
| explanation | TEXT | 详细解析 |
| estimated_time | INTEGER | 预计完成时间（分钟） |
| status | TEXT | 状态（draft 草稿 / published 已发布） |
| scoring_rubric | TEXT | 评分标准 |
| common_mistakes | TEXT | 常见错误 |
| cognitive_level | TEXT | 认知层次 |
| source | TEXT | 来源 |
| created_at | DATETIME | 创建时间 |

## 七、教案审计

### 9. `audit_logs` — 教案操作审计日志

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER (自增) | 主键 |
| plan_id | TEXT (索引) | 教案 ID |
| plan_name | TEXT | 教案名称（冗余） |
| course_name | TEXT | 课程名称 |
| chapter | TEXT | 章节 |
| operation | TEXT | 操作类型：create / view / edit / export / delete / restore |
| operator | TEXT | 操作人，默认"系统" |
| operator_role | TEXT | 角色（教师/管理员） |
| session_index | INTEGER | 修改的具体流程索引（null=全教案操作） |
| changes_before | TEXT (JSON) | 修改前快照 |
| changes_after | TEXT (JSON) | 修改后快照 |
| detail | TEXT | 操作描述 |
| ip_address | TEXT | 操作 IP |
| created_at | DATETIME (索引) | 操作时间 |

## 表关系图

```
lesson_plans ──┐
               ├── audit_logs (plan_id)
               └── plan_snapshots (plan_id)

homework_grades ─── exercise_batches (独立)

materials ─── questions (batch_id)

insight_reports (独立)

teaching_aux (独立)

llm_call_logs (独立)

agent_workflows (独立)

project_registry (独立)
```

## 互通相关字段

以下 4 张业务表带有 `project_id` 字段，用于区分数据来源：

| 表 | 互通数据 |
|------|------|
| `homework_grades` | 作业成绩 |
| `insight_reports` | 学情分析 |
| `materials` | 教学资料 |
| `teaching_aux` | 教学辅助素材 |

值约定：`ta-project`（助教端）/ `student-project`（助学端）。
